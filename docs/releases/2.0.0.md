## Changes since 1.4.1

- Installed GoBoard is now VR-only. The desktop keyboard remains available for debugging when running from source.
- Added a smaller Standard installer alongside the self-contained Offline installer.
- Toggling the numpad keeps the main keyboard in place, and the toggle stays above Num Lock.
- Floating Shortcuts stay compact until there is a message to display.
- Added a Close action to GoBoard's SteamVR dashboard page.

## Technical summary

VR keyboards and shortcut palettes now render directly into Skia GPU textures, with CPU rendering as a fallback. Smaller branding assets reduce installer overhead. Installer validation now covers setup/channel switching, rollback, and uninstall cleanup more thoroughly.

## Upgrade notes

The desktop keyboard Start menu shortcut is removed. An upgrade restarts a running desktop keyboard session in VR; use a source build if you need desktop debugging.

## Download and install

Requires Windows x64, SteamVR, and a headset.

Installation options:

- **Standard (.exe):** Installs .NET 10 if missing.
- **Offline (.msi):** Bundles .NET 10.
