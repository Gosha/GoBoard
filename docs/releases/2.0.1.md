## Changes since 2.0.0

- Old startup diagnostic logs are now removed automatically when GoBoard starts, preventing them from accumulating indefinitely.

## Technical summary

Startup log retention keeps at most the newest 20 logs and removes logs last written more than 30 days ago. Files that are in use or inaccessible are skipped and retried on a later launch; cleanup failures do not block startup.

## Download and install

Requires Windows x64, SteamVR, and a headset.

Installation options:

- **Standard (.exe):** Installs .NET 10 if missing.
- **Offline (.msi):** Bundles .NET 10.
