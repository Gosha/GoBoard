# GoBoard

GoBoard provides a desktop keyboard and a SteamVR keyboard with shared preferences.

## Language

**Settings editor**:
The GoBoard settings interaction that selects and saves keyboard preferences, including shortcut assignments, and offers sound auditions. It is available in a desktop window and a SteamVR dashboard tab.

**Sound audition**:
A preview of the saved sound choice and volume, subject to the sound-enabled preference. Selecting the same preset again also requests an audition.
